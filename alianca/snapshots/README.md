# snapshots

Pontos de **retomada**: documentos autocontidos que permitem reiniciar uma sessão (outro modelo, outra ferramenta, novo contexto) **sem depender do histórico anterior**.

Formato, conteúdo obrigatório, convenção de nome e regras: ver `../instructions/snapshot.md`. O mais recente é a fonte de verdade para retomada (`../START-HERE.md` §2).
